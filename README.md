# Mithai Box

A block-fit puzzle with Indian sweets. Drag mithai pieces into the 8x8 dabba, fill a row or column to clear it.

Play: https://heeray1.github.io/mithai-box/

- **Daily Box**: a new box every day, with the same pieces for everyone.
- **Endless**: play as long as you can.
- One HTML file, no libraries, works offline once loaded. Progress is saved on the device.

Testing: `index.html?bot=150` plays by itself (add `&mode=daily` for the Daily Box).
